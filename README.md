# Operaciones de Aprendizaje Automático

Repositorio correspondiente a la materia **Operaciones de Aprendizaje Automático**.

## Instalación y herramientas

Durante el curso se utilizarán diferentes herramientas y librerías de Python para el desarrollo, evaluación, despliegue y monitoreo de modelos de aprendizaje automático.

### Herramientas principales

| Herramienta        | Uso                                             |
| ------------------ | ----------------------------------------------- |
| Python             | Lenguaje de programación                        |
| Git                | Control de versiones                            |
| GitHub Desktop     | Gestión de repositorios Git                     |
| Visual Studio Code | Entorno de desarrollo                           |
| MLflow             | Seguimiento y gestión de experimentos y modelos |
| FastAPI            | Desarrollo de APIs para modelos                 |
| Evidently          | Monitoreo y evaluación de modelos y datos       |
| Pytest             | Pruebas automatizadas                           |
| SDV                | Generación de datos sintéticos                  |
| Deepchecks         | Validación y monitoreo de datos y modelos       |
| ONNX Runtime       | Ejecución/despliegue de modelos                 |
| WSL                | Entorno Linux para Windows                      |
| Podman             | Contenedores                                    |
